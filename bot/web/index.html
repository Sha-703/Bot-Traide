Connexion à la plateforme

Jeton de session (SSID) — jamais d'email ni de mot de passe.

Un jeton, pas un mot de passe. Le SSID est un jeton temporaire extrait d'une session déjà ouverte dans votre navigateur. Il reste en mémoire vive : jamais écrit sur disque, jamais journalisé, effacé dès l'arrêt de la console.

Une fenêtre Edge s'ouvre sur la page de connexion : vous tapez vous-même vos identifiants (la console ne les voit ni ne les enregistre). À la fin, la console lit la session et se connecte — aucun mot de passe dans l'outil.

Vérifie si le site et les serveurs de cotation répondent (aucune donnée envoyée).

    Où trouver le SSID ?
    1. Connectez-vous normalement à la plateforme dans Chrome ou Edge.
    2. Ouvrez les outils de développement (F12) puis l'onglet Réseau.
    3. Filtrez sur WS et cliquez la connexion socket.io.
    4. Dans Messages, repérez la trame d'authentification et copiez le jeton de session.

    Ce jeton expire vite et se révoque dès que vous vous déconnectez. Ne le partagez avec personne : il donne accès à votre compte.

    Ce n'est pas un robot exécuté à votre place. Avec un compte démo, les ordres passent en argent virtuel via votre session ; avec un compte réel, la console envoie de vrais ordres selon la stratégie (mode réel verrouillé tant que vous ne l'activez pas). Les CGU de la plateforme peuvent interdire ce type d'accès.
